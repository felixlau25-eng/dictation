# 自主默書小助手

功課班學生自行聽寫、對卷。支援 **香港粵語** 報讀，**詞語 / 句子 / 篇章**，**拍照輸入**，以及 **默書庫**。

線上使用：https://felixlau25-eng.github.io/dictation/

## 功能

### 默書庫
同一部平板輪流默書時，不用每次刪掉舊內容再貼新的。
- **儲存這份**：替清單起名（例如「三年級 單元二」「小明 生字」）
- **使用**：一按載入，可立刻開始默書
- **更新**：改過內容後寫回同一份
- 資料只存在這部平板的瀏覽器，沒有登入

### 拍照輸入
拍課本、詞語表或工作紙，或從相簿選圖，自動抽出文字做成默書清單。
- 會去掉頁碼、單元標題、姓名欄
- 可判斷詞語／句子／篇章
- 採用前可先改字，可取代或加到現有內容
- 此 GitHub 頁用本機辨識，首次使用需下載中文檔，請用網絡

### 廣東話發音
- 粵語預設用雲端香港粵語，讀書面語字音
- 有本機粵語（iPhone 善怡）才用本機
- 不會改用普通話
- 詞語可選「先逐字、再讀整詞」

### 默書範圍
| 範圍 | 用法 |
| --- | --- |
| **詞語** | 生字、詞彙、成語。一行一個 |
| **句子** | 一行一句 |
| **篇章** | 短文。先全文導讀，再逐句默寫 |

## 用法
1. 選紙筆實戰或螢幕打字
2. 選範圍，貼上內容、拍照，或從 **默書庫** 提取
3. 選廣東話，按「試聽發音」
4. 開始默書；完成後紅筆對卷，可重溫錯題
