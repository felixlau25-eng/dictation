# 自主默書小助手

功課班學生自行聽寫、對卷。支援 **香港粵語** 報讀，**詞語 / 句子 / 篇章**，以及 **拍照輸入**。

線上使用：https://felixlau25-eng.github.io/dictation/

## 功能

### 拍照輸入
拍課本、詞語表或工作紙，或從相簿選圖，自動抽出文字做成默書清單。
- 會去掉頁碼、單元標題、姓名欄
- 可判斷詞語／句子／篇章
- 採用前可先改字，可取代或加到現有內容
- 此 GitHub 頁用本機辨識，首次使用需下載中文檔，請用網絡

### 廣東話發音
- 粵語預設用雲端香港粵語，讀書面語字音
- 有本機粵語（iPhone 善怡）才用本機
- 不會改用普通話
- 詞語可選「先逐字、再讀整詞」

### 默書範圍
| 範圍 | 用法 |
| --- | --- |
| **詞語** | 生字、詞彙、成語。一行一個 |
| **句子** | 一行一句 |
| **篇章** | 短文。先全文導讀，再逐句默寫 |

## 用法
1. 選紙筆實戰或螢幕打字
2. 選範圍，貼上內容、用範例，或 **拍照輸入**
3. 選廣東話，按「試聽發音」
4. 開始默書；完成後紅筆對卷，可重溫錯題
