# 自主默書小助手

功課班學生自行聽寫、對卷。支援 **香港粵語** 報讀，以及 **詞語 / 句子 / 篇章** 三種默書範圍。

線上使用：https://felixlau25-eng.github.io/dictation/

## 這次改良

### 1. 廣東話發音
舊版用瀏覽器 `speechSynthesis` 配 `zh-HK`。Android 平板／Chrome 多數 **沒有粵語語音**，會默默改用普通話，聽起來就不準。

新版：
- 粵語預設用 **雲端香港粵語**（Google `yue`），讀 **書面語字音**（例如「我們」讀 *ngo5 mun4*，不是口語「我哋」）
- 偵測到真正的本機粵語（iPhone／iPad 的「善怡 Sinji」、部分 Windows 曉曼）才用本機
- **不會** 在粵語模式下改用普通話
- 詞語可選「先逐字、再讀整詞」，較接近導師報讀

試聽時會顯示目前引擎。若雲端無法播放，請檢查網絡；系統寧可不讀，也不會讀成普通話。

### 2. 默書範圍
| 範圍 | 用法 |
| --- | --- |
| **詞語** | 生字、詞彙、成語。一行一個，或用逗號分隔 |
| **句子** | 一行一句；有句號會自動分題 |
| **篇章** | 短文。先全文導讀，再逐句默寫。空一行可分開多篇 |

寫字時間可設「按題目長短自動」。

## 用法
1. 選紙筆實戰或螢幕打字
2. 選詞語／句子／篇章，貼上內容（或用快速範例）
3. 選廣東話，按「試聽發音」確認是粵語
4. 開始默書；完成後紅筆對卷，可重溫錯題

設定會自動記在本機瀏覽器。
